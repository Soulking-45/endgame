Q7)Family Program
Facts:
Family members: John, Mike, David, Lesa, Susan, Anna

Define:

male(X)
female(X)
parent(Y, X)

Rules:  
a) If 𝑥 is male and 𝑦 is parent of  𝑥  → father(y, x)
b) If 𝑥 is female and 𝑦 is parent of  𝑥 → mother(y, x)

Queries:  
a) Check if John is father of Mike
b) Check if Susan is mother of Mike
c) Find the mother of David
d) Find the father of Lesa
e) List all mothers

Family Tree Program
Facts:

prolog
male(john).
male(mike).
male(jake).

female(susan).
female(mary).
female(anna).

parent(john, mike).
parent(john, susan).
parent(susan, jake).
parent(mike, mary).
parent(anna, jake).
Rules:

prolog
father(F, C) :- male(F), parent(F, C).
mother(M, C) :- female(M), parent(M, C).
grandparent(Gp, C) :- parent(Gp, P), parent(P, C).
sibling(X, Y) :- parent(P, X), parent(P, Y), X \= Y.
Queries and Results:

parent(susan, jake). → True

sibling(mike, susan). → True
